# C Practice

A structured repository for C programming exercises, problem-solving, and practice sheets.

## Directory Overview

### 📁 Simple Sequence
Contains foundational C programs covering basic arithmetic, geometry formulas, conversions, and board question practices:
- **Arithmetic**: Addition, Subtraction, Multiplication, Division, Average (`1.add.c` - `5.avg.c`)
- **Geometry**: Circle area, Triangle area methods, Rectangle area (`6.circle.c` - `9.rectangle.c`)
- **Conversions**: Celsius to Fahrenheit & Fahrenheit to Celsius (`10.C-F.c`, `11.F-C.c`)
- **Board Questions & Exercises**: HSC/Board problem practices (`12.RjB-17d.c` - `20.d.c`, `bs1.c`, `bs2.c`)

---

## How to Compile & Run (Linux)
```bash
gcc "Simple Sequence/1.add.c" -o test.out
./test.out
```
